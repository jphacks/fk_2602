# モザリア（Mozaria）

> **見せたい顔だけ、見せる配信。**

**モザリア**は、ライブ配信に映り込む人のプライバシーを考え、AIによる顔認識とリアルタイム映像加工を組み合わせた配信支援アプリです。事前に登録した人物の顔はそのまま、未登録の人物の顔は初期状態でモザイク表示します。配信者は人物ごとに加工方法を切り替えられます。

**動作実績：** 加工済み映像を既存のライブ配信アプリ(Twitch)へウィンドウ共有し、実際に配信できることを確認しました。



## 製品概要

### 背景（製品開発のきっかけ、課題等）

ライブ配信中、配信者の周囲にいる友人や通行人など、**顔を公開するつもりのない人が意図せず映り込む**ことがあります。一度公開された映像は、スクリーンショットや録画などで残る可能性があり、配信後の編集だけでは対応できません。

一方で、映像全体をぼかしたり全員の顔を隠したりすると、配信者自身の表情や配信の臨場感まで失われてしまいます。

そこで、**「配信者の顔は見せながら、ほかの人の顔は配信中に保護できないか」**という課題から、モザリアを開発しました。

### 製品説明（具体的な製品の説明）

モザリアはWebカメラ映像から顔を検出し、登録した顔の特徴との照合により、登録者と未登録者を区別します。**未登録者は初期状態でモザイク**となり、必要に応じて絵文字への変更、登録済み顔画像への置換、加工解除が可能です。

画面は次の3つに分かれます。

| 画面 | 役割 |
| --- | --- |
| **① LIVE INPUT** | Webカメラの入力映像 |
| **② PRIVACY OUTPUT** | 顔ID・顔枠・操作ボタンを重ねた操作用映像 |
| **③ CLEAN LIVE** | 顔ID・操作ボタンを除いた、共有用の加工済み映像 |

③を配信アプリのウィンドウ共有で取り込むことで、既存の配信環境と組み合わせて使用できます。

### 特長

#### 1. 3回の撮影だけで、配信者の顔を登録

正面・右向き・左向きの3方向をWebカメラで撮影して登録します。楕円ガイドと撮影済み写真のサムネイルを用意し、登録操作を簡単にしました。

#### 2. 未登録者を初期状態でモザイク処理

顔認識によって登録済みの人物とそれ以外を判別し、**未登録者の顔を自動的にモザイク加工**します。背景全体のぼかしは必要に応じて切り替え可能です。

#### 3. 映像を見ながら個別・一括で加工を変更

顔の近くの **M / E / R / C**、または映像上部の **ALL M / ALL E / ALL R / ALL C** で加工を切り替えられます。

| 操作 | 機能 |
| --- | --- |
| **M / ALL M** | モザイク |
| **E / ALL E** | 表情に応じた絵文字表示 |
| **R / ALL R** | 登録した顔画像への置換 |
| **C / ALL C** | モザイク・絵文字・置換などを解除して元の顔を表示 |

一括操作ボタンは収納でき、操作パネルは映像の下にまとめています。音声コマンド用のマイク操作も用意しています。

### 解決できること

- ライブ配信中に映り込んだ未登録者の顔を、手動で編集することなく加工できます。
- 配信者の表情を残しながら、第三者の顔だけを隠す運用を支援します。
- 顔ごとの加工変更や一括操作によって、配信状況に合わせた対応ができます。
- **加工済みの③ CLEAN LIVEだけを既存の配信アプリに共有**することで、独自の配信サービスを作らずに利用できます。

> **注意：**配信前に必ず③の映像を確認し、加工解除（C / ALL C）は対象者の同意がある場合だけ使用してください。

### 今後の展望

- 人が移動したり顔の向きが変わったりした場合の認識・追跡精度の改善
- 顔検出に失敗したときに元映像が露出しにくい、安全側の映像処理
- 動画処理の軽量化と遅延の低減
- 仮想カメラや配信ソフトとの直接連携
- 表情解析に応じて絵文字を切り替える方式を制作中


### 注力したこと（こだわり等）

- **配信者に負担をかけない操作性：** 3方向の顔登録、画面上のM/E/R/Xボタン、一括操作、収納式パネルを実装。
- **操作画面と共有画面の分離：** 顔IDや操作ボタンを視聴者に見せず、加工後の映像だけを共有できる3画面構成。
- **実際の配信で使える形：** Twitchなど、既存の配信アプリでウィンドウ共有による配信に成功。
- **見やすさの改善：** タブやアイコン、文字色、コントラスト、操作領域を調整し、デモ中でも操作しやすいUIを目指しました。

## 開発技術

### 活用した技術

#### API・データ

- **InsightFaceの学習済み顔認識モデル（buffalo_l）**：顔検出と顔特徴ベクトルの抽出
- **Google Speech Recognition**：日本語の音声コマンド認識（任意機能、ネット接続が必要）
- **登録顔画像・特徴ベクトル**：ユーザーが撮影した正面・左右の顔画像と、そこから抽出した照合用データ

#### フレームワーク・ライブラリ・モジュール

- **Python**：アプリケーション全体の実装
- **Gradio**：ブラウザ上のUI、カメラ入力、操作画面
- **OpenCV**：映像フレーム処理、モザイク、顔画像置換、画面上の表示
- **InsightFace / ONNX Runtime**：顔検出・顔認識モデルの推論
- **MediaPipe**：表情情報の解析（対応モデルファイルがある場合）
- **NumPy / Pillow**：画像配列・画像ファイルの処理
- **SpeechRecognition**：音声コマンドの文字起こし

#### デバイス

- **Windows PC**（Python 3.10推奨）
- **Webカメラ**
- **マイク**（音声コマンド利用時）

### 独自技術

#### ハッカソンで開発した独自機能・技術

- **3方向の顔登録フロー：** 顔位置の楕円ガイド、1回ずつの撮影、撮影済みサムネイル、登録画像の保存を一連の操作にまとめました。
- **登録者と未登録者で異なる映像加工：** 顔特徴ベクトルを照合し、未登録者だけを初期状態でモザイク加工します。
- **顔IDに基づく表示切り替え：** 顔を追跡し、個別のM/E/R/X操作と全員への一括操作を反映します。
- **操作用と配信用の映像を同時生成：** ②には顔枠やボタンを描画し、③には加工結果のみを表示します。
- **配信アプリへの接続実績：** ③をウィンドウ共有で配信アプリに取り込み、ライブ配信で利用できることを確認しました。

**主な実装ファイル：** [`app.py`](./app.py)（顔登録、追跡、加工、UIを実装）

## 動かし方

Windows PowerShellでプロジェクトのディレクトリに移動し、以下を実行します。

```powershell
py -3.10 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

ブラウザで `http://127.0.0.1:7860` にアクセスします。

顔登録は「登録」タブ、加工確認は「カメラ」タブで行います。配信するときは、**③ CLEAN LIVEの映像部分だけ**を取り込んでください。未加工の①を誤って共有しないよう注意してください。

※ 音声認識機能は音声コマンド用です。
